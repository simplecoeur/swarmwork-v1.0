# 快速上手

干活蜂群是一支住在服务器上的 AI 团队：你发单，他们干活、互相审核，最后把成果交到你手里。

## 五步开工

注册开公司时会走一遍五步问卷（公司信息 → 接入你的 AI → 关于你 → 提醒与督促 → 确认），开完公司后再补这几步就能正式开工：

- 第一步：在「设置后台」给至少一条 API 填上 Key（Key 加密保存在服务器，页面只显示掩码）；问卷里已接入的可跳过这一步
- 第二步：在「成本中心」采购充值，余额大于 0 才能开工；新空间一般有一笔体验额度可先试跑
- 第三步：回办公室发单，或用新手卡一键试跑一个官方技能
- 第四步：把公司标准、常用资料放进「知识库」，之后每单干活都会自动引用（知识库面板有「搜索测试」可先验命中）
- 第五步：到「资源中心」逛逛技能库与人才库，安装现成技能、招募现成智能体，团队立刻变厚

## 办公室与发单

- 办公室里的像素小人就是你的成员，小人状态由真实任务驱动；点小人可以改他的专属提示词
- 发单有这些方式：单任务、方案下发（组长自动拆成子任务）、批量发单（一行一单）、定时任务（每天/每周到点自动发）、从技能一键发单（套用技能参数直接成单）、从任务模板新建
- 技能页可以安装官方技能，填参数一键发单；技能还能把成果沉淀成「已验证做法」越用越准

## 任务会经历什么

- 任务进队列后由对口工种领取执行，产出后由审核成员按审核要点逐条核对
- 审核不过会被打回重做；打回满次或预算超限会转「待裁决」，等你在任务墙一锤定音
- 每单都能展开「过程时间线」：拆单、注入了哪些知识与资产、每次调用的耗时与成本，一步不落

## 数据在哪

- 全部业务数据都在服务器应用数据目录的 SQLite 单文件里，没有云端副本
- 整库备份是平台管理员专属功能（在管理台下载，文件含全部空间数据）；空间所有者要拿自己的数据，在「设置后台 → 数据管理」用空间全量导出（点「导出本空间全部数据（zip）」），导出的 zip 只含本空间数据；成本中心有按月台账 CSV 导出
