# 高频问题

## API Key 怎么配？

到「设置后台 → API 配置」新增或编辑一条 API：选厂商、填 Base URL、模型名与 Key，保存后点「测试连接」确认能通。再到「成本中心」给这条 API 采购充值，任务才会真正开工。Key 只加密保存在服务器数据库里，任何页面和接口都只回掩码。

## 裁决是什么？

任务被审核打回满次、或单任务 token 消耗达到预算上限时，会停在「待裁决」等你拍板：

- 裁决通过：成果直接交付（会单独标注是老板裁决通过，不受预算闸门拦截）
- 不处理：任务就停在那里，不会继续消耗

待裁决会第一时间通过站内通知提醒你（顶栏铃铛）。

## 体验额度是什么？

新空间的冷启动额度，由平台管理员发放：小额、一次性、不可续发叠加。体验额度走平台体验 API，用完后任务会停工并提示你填自己的 API Key。体验余额与自有余额在成本中心分开显示。

## 余额预警线怎么设？

成本中心顶部摘要卡里可以设置低余额阈值：余额跌破阈值会收到一条站内「余额预警」通知，充回去之后再跌破才会再提醒，不会反复轰炸。不设置时默认按最近一笔采购额的 20% 计算。

## 每单大概花多少钱？

发单确认区会显示同类任务近 30 天的平均成本与区间（样本不足时按全空间均值估算）。还没有历史时显示「暂无历史，跑几单后可预估」。

## 忘了密码怎么办？

本版暂未开通邮箱自助找回，请联系平台管理员在管理台重置密码，你会拿到一个临时密码，登录后必须先改密才能继续使用。
