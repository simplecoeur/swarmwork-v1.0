# ADR-006 产品形态定版为 Web 端（取消桌面打包）

- 状态：Accepted（2026-10-23，用户改定）
- 关系：supersede ADR-001 中"桌面应用"部分；ADR-001 的"数据存用户本地"原则不变

## 背景

ADR-001 曾定正式版做桌面端（Tauri/Electron 壳），理由是数据主权。M1/M2 落地后用户复核认为：Web 端功能已经配齐（设置后台、多 API 分配、成本中心、小组管理、审核标准均在网页内），桌面壳只是更换打开方式、不增加任何功能，却多出打包、签名、升级维护成本。

## 决策

- 产品形态定版为 **Web 端**：本地版以"本地服务 + 浏览器打开"形态交付（后端仅监听 127.0.0.1，数据存本机 SQLite）。
- 取消桌面打包里程碑（原 M4），不再引入 Tauri/Electron。
- 数据主权由部署方式保证，与形态解耦：服务跑在本机则数据在本机；后续如需随时访问，可将同一套服务部署到用户自有 VPS，前端与数据结构不变。

## 后果

- 工程重心回到 Web 功能本身（M3 知识库等），不为打包分心。
- 分发方式为源码包/仓库交付，用户本地 `npm install && npm run build` 后启动服务使用。
