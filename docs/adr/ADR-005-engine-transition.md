# ADR-005：Muse 本人当发动机仅为过渡形态

- 状态：已采纳（2026-10-23）
- 出处：技术设计文档 §14

## 背景

「真干活版」验证阶段曾由 Muse 本人充当任务发动机（巡检领取→产出→自审→回填），证明了任务闭环的产品形态成立。

## 决策

该形态仅为过渡验证手段，不构成产品依赖。正式引擎为用户自配的多条大模型 API（见 ADR-002），由本地服务端调度引擎统一领取、执行、审核与记账。

## 理由

- 产品必须能在用户本机独立运行，不依赖特定 AI 助手在线。
- 自配 API 后成本、可用性与数据流向完全由用户掌控。

## 影响

- 引擎按 Provider 接口实现，执行/审核/拆单均为可替换的模型调用；温度、重试、熔断、估算口径见技术设计文档 §15 决策补充。
