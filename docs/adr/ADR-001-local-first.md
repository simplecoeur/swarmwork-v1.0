# ADR-001：桌面端本地优先

- 状态：已采纳（2026-10-23）
- 出处：技术设计文档 §14

## 背景

产品涉及用户的 API Key、甲方需求、成本账本等敏感数据，需要决定数据与运行形态：云端托管还是本地优先。

## 决策

本地优先：全部数据（含 API Key）只存用户本机，服务端只监听 127.0.0.1，不依赖任何云端服务；产品形态先行交付为本地服务 + 浏览器，后续打包桌面端（Tauri/Electron）。

## 理由

- 数据主权与 Key 安全优先于多端便利：Key 不出本机，日志与接口响应一律掩码。
- 本地单机场景下运维成本最低，用户解压即可运行。

## 代价与后续

- 无 7×24 持续运行：电脑关机即停工。后续以「引擎迁自有 VPS」里程碑补齐，桌面端退化为控制台。
- 多设备同步不在本期范围。
